# 按键、UI 与 OLED 整合路径

最后更新：2026-07-26

## 目标

在不依赖 NE555、EEPROM 或波形测量设备的条件下，验证已完成的按键、UI 状态和 OLED 模块能够协同工作。

## 数据流

```text
K1-K4 -> bsp_key -> main 高层调度 -> app_ui 状态 -> bsp_oled -> OLED
                                      -> USART1 调试输出
```

## 按键规则

| 按键 | GPIO | 行为 |
| --- | --- | --- |
| K1 | PB12 | 返回监测页 |
| K2 | PB13 | 进入标定页 |
| K3 | PB14 | 在标定页标记数据已修改 |
| K4 | PB15 | 标定页进入保存确认页；确认页再次按下确认并返回监测页 |

## 非顺序按键规则

- 监测页：仅 K2 进入标定页，并从干净状态开始；其他按键不改变页面。
- 标定页：K1 返回监测页，K3 标记修改，K4 进入保存确认页，K2 不改变页面。
- 保存确认页：K1 或 K2 取消确认并返回标定页且保留修改状态，K4 确认保存并返回监测页，K3 不改变页面。
- 不改变页面的按键会由串口输出 `UI action ignored`，这是预期行为而非按键故障。

## 页面与验证

| 页面 | OLED 预期内容 | 进入方式 |
| --- | --- | --- |
| 监测页 | `FREQ: 0`、`COUNT: 0` | 上电或 K1 |
| 标定页 | `CAL MODE`、`EDIT` 或 `DIRTY` | K2、K3 |
| 保存确认页 | `SAVE CAL?`、`K4: YES` | 标定页按 K4 |

## 操作顺序

1. 断电并确认 PB0 至 PA0 的测频自测跳线已拆除。
2. Keil 编译并下载整合程序。
3. 验证上电监测页、K2 标定页、K3 修改状态、两次 K4 保存确认流程和 K1 返回。
4. 同时确认串口事件和 PC13 LED 持续正常。
5. 通过后更新 `Memory/progress.md` 并创建本地提交。
