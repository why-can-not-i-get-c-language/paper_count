## 当前优先级

1. 完成当前标定编辑软件的 Keil 编译与基础 UI 验证。
2. 等待蜂鸣器驱动元件；元件齐全后完成安全驱动、接线和功能验证。
3. 等待 NE555 及电平转换方案；先做万用表静态检查，再接 PA0。
4. 收集真实纸张频率数据，建立最多 16 点标定表，验证保存、恢复和计数。

## 标定编辑规则

- 监测页 K2：从正式标定表创建编辑副本并进入标定页。
- 标定页 K2：纸张张数在 0~80 间循环；K3：捕获当前频率到该张数；K1：放弃编辑副本。
- 标定页 K4：进入保存确认；确认页 K4：保存编辑副本，成功后回监测页；失败时停留确认页。
- 编辑点按频率升序保存，频率重复会被拒绝。

## 验证边界

- 代码完成、Keil 编译通过、硬件验证通过是不同状态，记录时必须区分。
- 未经用户解锁，不进行或宣称完成波形、过冲、毛刺、占空比、传感器噪声验证。
- 每个通过的可验证小任务都应更新 Memory、提交并推送 GitHub。
