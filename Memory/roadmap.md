## 实施顺序

1. 保留当前面包板作为电子基线，确认 PA0 测频仍正常。
2. 设计 NE555 电子 PCB。PCB 只放电子电路、接线端子和测试点，不把两块铜板焊死在主板上。
3. PCB 至少保留 `RA`、`RB`、定时电容的可替换焊盘或插座；最终阻容值未因纸张测试而冻结。
4. 设计 3D 打印机械夹具：两块 50mm x 50mm 铜板平行、间距可调、绝缘、压力可重复、导线有固定和应力释放。
5. PCB 焊接后先不接 PA0，复测 NE555 `3脚 OUT` 和 S8050 `C`；通过后再接 PA0。
6. 在夹具中测试空载、1、5、10 张及更多纸张，每种状态多次记录串口和示波器频率。
7. 根据数据冻结阻容和机械尺寸，建立最多 16 个真实标定点。
8. 机械结构完成并得到可分离频率后，验证 K3 捕获、K4 保存、AT24C08 掉电恢复和整机计数；当前仅验证功能路径，不采纳临时标定数据。

## NE555 初始电路基线

```text
NE555 1 GND -> 公共 GND
NE555 8 VCC -> 5V；4 RESET -> 5V
NE555 2 TRIG 与 6 THRES 短接为定时节点
5V -> 10kOhm -> 7 DISCH -> 100kOhm -> 定时节点
定时节点 -> 470pF -> GND，并接传感铜板 A
传感铜板 B -> GND
5 CONT -> 10nF -> GND
8 VCC 与 1 GND 之间：100nF 并联 10uF
3 OUT -> 10kOhm -> S8050 B；S8050 E -> GND
S8050 B -> 100kOhm -> GND；S8050 C -> 4.7kOhm -> STM32 3.3V
S8050 C -> PA0
```

`10kOhm`、`100kOhm`、`470pF` 是当前可工作的初始值，不是最终标定值。`1N4148` 暂不装入 NE555 基础电路。

## PCB 边界

- 应放入 PCB：NE555、S8050、全部固定/可替换阻容、5V/3.3V/GND 接线端子、SENSOR 接口、PA0 接口、示波器测试点。
- 不应直接焊入主 PCB：两块 50mm x 50mm 铜板、纸张夹具和 3D 结构件。铜板应通过短线和可拆接插件连接，便于调整间距和更换机械结构。
- PCB 需要按实际封装建库：插件 NE555 DIP-8、插件电阻电容、S8050 的实际 `E/B/C` 排列；封装方向必须在丝印上标出。
- 首版已确认全部优先采用插件元件并由用户自行焊接；继续外接 STM32 核心板、OLED、AT24C08 和按键。第二版再评估这些模块的板级集成。
- 使用嘉立创 EDA 专业版逐步设计，采用普通双层板、常规板材和常规工艺，板框控制在 100mm x 100mm 以内。免费打板属于下单活动条件，提交前仍需按当时订单页面逐项核对。
- 本轮暂不设计 3D 机械夹具，但铜板接口必须保持可拆，不能妨碍后续夹具设计。
- NE555 前端板与后续核心板之间使用 2.54 mm 杜邦线，不把两块板直接叠焊或固定成不可拆结构。
- NE555 前端板四角设置机械安装孔；当前用户已有 M4、160 mm 螺纹螺杆，因此孔径、铜环和板边距离需在 PCB 封装/板框阶段按实际 M4 五金件核对。安装孔默认无铜、无网络连接。
- “至少两块、可能三块”只作为系统规划；第三块的功能和边界尚未确认，不应写入首版 NE555 原理图。
