# 项目架构与工作责任

## 目标

测量两块铜箔极板夹入纸张后产生的电容变化。NE555 将电容变化转换为方波频率，STM32 测量频率并通过标定表换算纸张数量，最后在 OLED 和串口显示结果。

## 数据流

```text
纸张与极板 -> NE555 方波 -> STM32 定时器测频 -> 滤波与稳定判断
-> 标定表换算张数 -> OLED/串口显示
                       -> AT24C08 保存或读取标定表
```

## 已确认硬件约束

- MCU 为 STM32F103C8T6。
- PC13 是核心板板载 LED，通常为低电平点亮。
- PA13、PA14 保留给 ST-LINK 调试。
- NE555 以独立 5 V 电源工作；其输出通过 NPN 开集电极转换并由 STM32 3.3 V 上拉后才允许进入 PA0。
- OLED 为 0.96 英寸、128x64、白色单色 I2C 模块，驱动芯片为 SSD1306。
- OLED 使用 3.3 V 供电，SCL/SDA 逻辑电平不得超过 3.3 V。
- OLED 默认 7 位 I2C 地址为 0x3C；模块可配置为 0x3D。
- OLED 模块板载 SCL/SDA 至 VCC 的 4.7 kΩ 上拉电阻。

当前已经确认的实际接线与对应核心板接口统一记录在 `Memory/wiring_map.md`；本文件不再重复维护具体连线。

## 待确认硬件信息

- 蜂鸣器已确认是 12085P 16 Ω 档插针式无源蜂鸣器，壳体 `+` 标识为正极，额定电压 1.5 V、额定电流不超过 30 mA、谐振频率约 2048 Hz，实测直流电阻约 16 Ω。不得直接接入 3.3 V GPIO；待确认三极管、限流电阻和续流二极管后确定安全驱动电路。
- NE555 的最终定时电阻、传感电容的实际范围、频率范围与机械夹具结构。当前电子链路已接线验证，但正式标定前仍需固定机械结构。
