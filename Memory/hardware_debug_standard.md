# 硬件调试说明标准

最后更新：2026-08-11

## 安全规则

- 接线、拔线和通断测量必须断电。
- STM32 GPIO 不得接收 5V；NE555 `3脚 OUT` 必须经过 S8050 后才可到 PA0。
- PA13、PA14 只给 ST-LINK 使用；PB0 至 PA0 的自测跳线默认拆除。
- ST-LINK 的 3.3V 只给 STM32 和 3.3V 逻辑使用；NE555 使用约 5V；两者共 GND。
- 示波器 10X 探头的地夹接公共 GND，不能接 5V、3.3V 或信号线。

## 引脚辨识规则

说明任何芯片、三极管、二极管或模块时，必须先说明型号、封装方向、引脚名称、功能和实物辨识方式；不能按外形猜测。

### NE555 DIP-8

插件芯片缺口或圆点朝上，左上角为 1 脚，逆时针编号：

| 脚 | 名称 | 本项目接法 |
| --- | --- | --- |
| 1 | GND | 公共 GND |
| 2 | TRIG | 与 6 脚接定时节点 |
| 3 | OUT | 接示波器，再经 10kOhm 到 S8050 B |
| 4 | RESET | 5V |
| 5 | CONT | 10nF 到 GND |
| 6 | THRES | 与 2 脚接定时节点 |
| 7 | DISCH | 接 10kOhm/100kOhm 定时电阻网络 |
| 8 | VCC | 约 5V |

### S8050

S8050 的 `E/B/C` 排列必须按手中器件数据确认。当前电路使用：`E -> GND`、`B -> 10kOhm -> NE555 3脚`、`B -> 100kOhm -> GND`、`C -> 4.7kOhm -> STM32 3.3V`、`C -> PA0`。

## 首次检查顺序

1. 断电核对 NE555、定时电阻、470pF、10nF、100nF、10uF 和 S8050 的接线；确认 `S8050 C -> PA0` 可断开。
2. 直流电压档，黑表笔接 GND：NE555 8 脚对 1 脚约 4.8~5.0V，4 脚对 1 脚约 5V，STM32 3.3V 对 GND 约 3.3V。
3. 示波器探头 10X、通道 10X、DC 耦合、1V/div、100us/div、上升沿触发；测 NE555 3 脚，应为约 0~5V 方波。
4. 测 S8050 `C`，应为与 NE555 同频的反相约 0~3.3V 方波；短地线和 20MHz 限带下不应有持续超过 3.6V 的过冲。
5. 只有第 3、4 步通过后，断电把 S8050 `C` 接回 PA0，再观察串口频率。

## 异常处理

- NE555 3 脚无波形：先查 4 脚 RESET、2/6 脚短接、7 脚两只电阻和定时电容。
- S8050 `C` 始终为 0V：查 `E/B/C` 排列、4.7kOhm 上拉和 10kOhm 基极电阻。
- S8050 `C` 始终为 3.3V：查 NE555 3 脚波形、10kOhm、100kOhm 和 S8050 `E/B/C`。
- 纸张数据重叠：先固定机械间距和压力，不要先伪造标定点或大改软件。
