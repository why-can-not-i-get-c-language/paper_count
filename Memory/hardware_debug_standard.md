# 硬件调试说明标准

最后更新：2026-07-25

## 目的

本文件规定后续所有硬件调试说明的固定写法。面向刚开始接线的操作，避免只给出 GPIO 名称而不说明器件、位置和接线方式。

## 每项调试必须说明的内容

1. **目标**：本次要验证的功能和成功判据。
2. **涉及器件**：逐一说明核心板、外设模块、按键、传感器、面包板和测试仪器各自的作用。
3. **引脚归属和辨识方式**：明确每个信号属于哪个器件；核心板引脚必须同时给出芯片端口名（例如 `PB12`）和板上寻找方式（查看排针旁同名丝印）。不得仅凭常见图片推断位置。
4. **所需材料和端头匹配**：明确是否需要面包板，以及公对公、公对母或母对母杜邦线；若端头不能直接插入面包板或模块，必须先说明所需转接方式。
5. **断电接线图**：用简单文字图表示每一条电气连接，并明确禁止连接到的电源或引脚。
6. **断电检查**：说明数字万用表应使用的档位、表笔位置及预期导通/不导通结果。
7. **上电检查**：说明数字万用表的电压档、黑红表笔连接位置和预期电压范围。
8. **软件验证**：说明 Keil 编译、下载、串口参数、OLED/LED 等预期表现，并明确按下、松开或其他操作与输出出现的先后关系。
9. **异常处理**：列出最先检查的接线、供电、电平或程序现象；没有确认安全电平前不得继续连接 MCU 引脚。

## 固定安全规则

- 所有接线、拔线和万用表通断测试均在核心板断电时进行。
- 使用电压档测量前确认黑表笔接核心板 `GND`，红表笔接被测信号。
- STM32F103C8T6 的 GPIO 不得直接接收 5 V 信号。NE555 等 5 V 逻辑输出接入 MCU 前必须完成 3.3 V 电平转换。
- PA13、PA14 保留给 ST-LINK 调试，不用于外设接线。
- 每次只新增一个外设或一个信号，验证成功后再增加下一项，避免同时引入多个故障点。
- 对标记为“等待波形测量设备”的任务，只允许进行断电通断、直流电压和 MCU 功能自测；不得以这些结果替代示波器或逻辑分析仪的波形结论。

## 按键接线基准示例

### 目标

验证按键按下时将 STM32 输入引脚拉低，并由串口输出对应按键事件。

### 器件和引脚

| 器件 | 连接点 | 作用和寻找方式 |
| --- | --- | --- |
| STM32F103C8T6 核心板 | `PB12` 排针 | 芯片 Port B 的第 12 个 GPIO；在核心板排针旁寻找 `PB12` 丝印。 |
| STM32F103C8T6 核心板 | `GND` 或 `G` 排针 | 系统地；在核心板排针旁寻找 `GND` 或 `G` 丝印。 |
| 轻触按键 K1 | 两组相对引脚 | 未按下时两组不导通，按下后两组导通。 |

### 接线

```text
核心板 PB12 排针 -> 杜邦线 -> K1 一组引脚
核心板 GND 排针  -> 杜邦线 -> K1 另一组引脚
```

按键插入面包板时跨过中间凹槽，避免同一组引脚被面包板内部排线短接。PB12 使用内部上拉，因此不需要外接电阻，也不得将按键接到 3.3 V 或 5 V。

### 验证

断电时，用万用表通断档测量 K1 两组引脚：未按下不导通，按下导通。上电后，以核心板 `GND` 为参考测 PB12：未按下约 3.3 V，按下约 0 V。Keil 下载后，串口设为 115200 bps；按下并松开 K1 后，出现 `KEY 1 pressed`。
