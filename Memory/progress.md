# 项目进度

最后更新：2026-08-13

## 当前结论

- STM32 基础板级功能已验证：SysTick、PC13 LED、USART1 PA9 115200、K1-K4、OLED、AT24C08 和标定算法均可工作。
- NE555 使用约 5V 供电，S8050 开集电极转换后接入 PA0；示波器检查未发现持续的危险过冲。
- PA0 测频联调已通过。串口持续输出 `System is running.`，频率约为 13.0~13.9kHz。
- 手工夹持铜板测试中，空载、1 张和 5 张纸的频率区间明显重叠；当前只能证明电路有输出，不能建立正式标定表。用户已确认在现有条件下可完成 K3 捕获、K4 保存和提示音功能测试，功能路径与真实标定分开记录。
- PCB 规划已确认：至少两块板，当前先设计独立 NE555 前端板；核心板、OLED、AT24C08、按键和蜂鸣器所在板后续再设计。板间使用 2.54 mm 杜邦线，NE555 前端板四角预留机械安装孔。

## 当前实际接线

长期有效接线只以 `wiring_map.md` 为准。PA0 已接 S8050 `C`，PB0 至 PA0 的 1kHz 自测跳线已拆除。

## 当前阻塞

- 铜板间距、平行度和压力不可重复，缺少机械夹具。
- NE555 定时阻容是可工作的初始值，但最终值必须在机械结构稳定后根据实测频率冻结。
- 蜂鸣器已完成独立接线、Keil 编译/下载和开机短鸣实测：上电后约响 150ms 后停止；PB1/TIM3_CH4、第二只 S8050 和 12085P 驱动链路正常，未影响 PA0 测频。主循环已接入计数成功、频率越界、标定捕获和 EEPROM 保存提示；用户已确认捕获/保存功能路径可正常完成。

## 下一步

1. 使用嘉立创 EDA 专业版绘制独立 NE555 前端板原理图，保持阻容可替换、PA0 电平隔离和测试点完整。
2. 核对 2.54 mm 杜邦线接口、四角机械安装孔和实际元件封装后，再进行 PCB 封装、布局布线和 DRC。
3. 首版 PCB 裸板焊接后，按硬件调试标准依次复测 NE555 OUT、S8050 C，再接回 PA0。
4. 保持当前软件版本，等待机械夹具完成后再采集真实频率和建立正式标定表。
5. 后续再设计第二块核心板；是否增加第三块 PCB 暂不决定。
6. 机械结构完成后，重新验证 EEPROM 标定表加载、计数成功短鸣和频率越界提示。

- 空载/1 张/5 张手工夹持数据已记录，但区间重叠，状态为“初测”，不是“标定完成”。
