# 当前接线与接口总表

最后更新：2026-07-26

## 使用范围

- 本文件只记录用户确认已经实际接线并有效的连接；不记录计划接线、未接线接口或推测结果。
- 新增、移除或确认一项实际接线后，均在本文件中更新。
- 核心板排针以丝印为准，例如 `PB6` 必须接到板上标有 `PB6` 的排针，不根据常见开发板图片猜测位置。

## 已接线并验证的 AT24C08

AT24C08 使用 DIP-8 封装，芯片缺口/圆点方向已经按实物确认。

| AT24C08 引脚 | 名称 | 核心板接口 | 已确认接法 |
| --- | --- | --- | --- |
| 1 | NC | 无 | 悬空。 |
| 2 | NC | 无 | 悬空。 |
| 3 | A2 | `GND` | 选择最低硬件地址配置。 |
| 4 | GND | `GND` | 与核心板和 OLED 共地。 |
| 5 | SDA | `PB7` | 与 OLED SDA 并联，共用软件 I2C 数据线。 |
| 6 | SCL | `PB6` | 与 OLED SCL 并联，共用软件 I2C 时钟线。 |
| 7 | WP | `GND` | 低电平允许写入。 |
| 8 | VCC | `3.3V` | 使用核心板 3.3 V 供电。 |

该接线已由用户完成断电与上电检查，当前状态正常。AT24C08 与 OLED 共用 I2C 总线但地址不同：OLED 为 `0x3C`；AT24C08 在 `A2=GND` 时按存储块使用 `0x50` 至 `0x53`。
