# 当前接线与接口总表

最后更新：2026-08-13

本文件只记录用户已实际接线并验证的连接。计划中的 PCB 端子、机械夹具和蜂鸣器不写入本表。

## 电源与调试

| 信号 | 连接 | 说明 |
| --- | --- | --- |
| STM32 3.3V | ST-LINK 3.3V -> 核心板 3.3V | STM32 和 S8050 集电极上拉使用。 |
| STM32 GND | ST-LINK GND -> 核心板 GND | 与 NE555 5V 电源负极共地。 |
| NE555 5V | ST-LINK 5V 实测约 4.9V -> NE555 8脚、4脚 | 仅供 NE555；不接 STM32 3.3V。 |
| SWD | ST-LINK SWDIO -> PA13；SWCLK -> PA14 | PA13/PA14 不接其他外设。 |
| 串口 | PA9 -> USB 串口 RXD；GND -> GND | USB 串口 VCC/TXD 不接；115200 bps。 |
| 板载 LED | PC13 | 低电平点亮。 |

## NE555 DIP-8

插件芯片缺口或圆点朝上，左上角为 1脚，逆时针编号：

| NE555 脚 | 名称 | 实际连接 |
| --- | --- | --- |
| 1 | GND | 公共 GND |
| 2 | TRIG | 与 6脚短接，接定时节点 |
| 3 | OUT | 经 10kOhm 接 S8050 B；不直接接 PA0 |
| 4 | RESET | 5V |
| 5 | CONT | 10nF 接 GND |
| 6 | THRES | 与 2脚短接，接定时节点 |
| 7 | DISCH | 接 10kOhm/100kOhm 定时电阻网络 |
| 8 | VCC | 约 5V；与 1脚之间有 100nF、10uF 去耦 |

## NE555 定时网络与铜板

```text
5V -> 10kOhm -> NE555 7脚
NE555 7脚 -> 100kOhm -> NE555 2/6脚定时节点
定时节点 -> 470pF -> GND
定时节点 -> 铜板 A
铜板 B -> GND
```

两块铜板为 50mm x 50mm，导线焊在铜层边缘；当前无机械夹具，间距和压力不可重复。

## S8050 与 PA0

S8050 的封装引脚排列必须按手中器件资料确认，以下用实物引脚名称表示：

```text
S8050 E -> GND
S8050 B -> 10kOhm -> NE555 3脚 OUT
S8050 B -> 100kOhm -> GND
S8050 C -> 4.7kOhm -> STM32 3.3V
S8050 C -> STM32 PA0 / TIM2_CH1
```

S8050 `C` 已用示波器检查，并已通过 PA0 串口测频联调。NE555 5V 输出禁止直接连接 STM32 GPIO。

## 蜂鸣器驱动

蜂鸣器使用第二只 S8050，与 PA0 测频用的 S8050 分开：

```text
STM32 PB1/TIM3_CH4 -> 4.7kOhm -> S8050 B
S8050 B -> 100kOhm -> GND
S8050 E -> GND
5V -> 150Ohm -> 12085P 蜂鸣器正极（+）
12085P 蜂鸣器负极（-） -> S8050 C
1N4148 阴极（有色环） -> 蜂鸣器正极
1N4148 阳极 -> 蜂鸣器负极 / S8050 C
```

S8050 的 `E/B/C` 必须按实际器件资料确认；PB1 只输出约 2048Hz 方波控制基极，蜂鸣器电流由 5V、150Ohm 和第二只 S8050 承担。蜂鸣器已完成上电静态检查、软件 PWM、开机短鸣和提示路径验证。
