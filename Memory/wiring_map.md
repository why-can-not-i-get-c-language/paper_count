# 当前接线与接口总表

最后更新：2026-07-27

## 使用范围

- 本文件只记录用户确认已经实际接线并有效的连接；不记录计划接线、临时排障步骤或未接线接口。
- 新增、移除或确认一项实际接线后，均在本文件中更新。
- 核心板排针以丝印为准，例如 `PB6` 必须接到板上标有 `PB6` 的排针，不根据常见开发板图片猜测位置。

## 电源、下载与串口

| 状态 | 核心板接口 | 对端/用途 | 已确认接法 |
| --- | --- | --- | --- |
| 已接线并验证 | `3.3V`、`GND`、`PA13`、`PA14` | ST-LINK | ST-LINK `3.3V -> 3.3V`、`GND -> GND`、`SWDIO -> PA13`、`SWCLK -> PA14`。ST-LINK 是核心板唯一供电源。 |
| 已接线并验证 | `PA9`、`GND` | USB 转串口模块 | `PA9 -> RXD`、`GND -> GND`，串口参数 115200 bps。模块 `VCC` 和 `TXD` 均不接。 |
| 板载固定 | `PC13` | 板载 LED | 低电平点亮；不作为外接 LED 或其他外设接口。 |

`PA13/PA14` 只供 ST-LINK 使用。USB 转串口模块和 ST-LINK 可以同时插入电脑，但 USB 转串口模块的 `VCC` 不连接核心板。

## 面包板电源轨

用户已用通断档确认：左 `+`、左 `-`、右 `+`、右 `-` 是四条彼此独立的长电源轨；每条自身从头到尾均导通。

- 当前使用一侧 `+` 长轨分配核心板 `3.3V`，一侧 `-` 长轨分配核心板 `GND`。
- 不使用的电源轨不接线；如未来需要扩展，只能桥接 `+ -> +`、`- -> -`。
- `PB6/PB7` 等 GPIO 信号不接电源轨，只在普通五孔排或点对点导线中连接。

OLED 为 SSD1306、128x64、7 位地址 `0x3C`。其板载 `SCL/SDA` 至 3.3 V 的 4.7 kOhm 上拉电阻已经通过实测验证。

## 已接线并验证的 AT24C08

AT24C08 使用 DIP-8 封装。芯片缺口或圆点朝上时，左上角为 1 脚；左侧从上到下是 1、2、3、4 脚，右侧从下到上是 5、6、7、8 脚。

| AT24C08 引脚 | 名称 | 核心板接口 | 已确认接法 |
| --- | --- | --- | --- |
| 1 | NC | 无 | 悬空。 |
| 2 | NC | 无 | 悬空。 |
| 3 | A2 | `GND` | 选择最低硬件地址配置。 |
| 4 | GND | `GND` | 与核心板和 OLED 共地。 |
| 5 | SDA | `PB7` | 与 OLED `SDA` 并联，共用软件 I2C 数据线。 |
| 6 | SCL | `PB6` | 与 OLED `SCL` 并联，共用软件 I2C 时钟线。 |
| 7 | WP | `GND` | 低电平允许写入。 |
| 8 | VCC | `3.3V` | 使用核心板 3.3 V 供电。 |

AT24C08 与 OLED 共用 I2C 总线但地址不同：OLED 为 `0x3C`；AT24C08 在 `A2=GND` 时按存储块使用 `0x50` 至 `0x53`。

| 核心板接口/器件 | 状态与限制 |
| --- | --- |
| `PA0` | 未接，等待 NE555 和已确认的 5 V 转 3.3 V 电平转换。 |
